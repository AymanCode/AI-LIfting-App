# Changelog

## 2026-10-23

The Android keyboard covered the IronMind composer and some Cardio inputs, while copied web padding squeezed Split forms twice. This hid typed text and actions and wasted the space above the keyboard. The native app container now consumes the keyboard inset once, keeps the tab reservation in the same inset calculation, sizes Log and swap content to the remaining space, and scrolls IronMind settings, new messages, and Cardio notes with their actions into view.
